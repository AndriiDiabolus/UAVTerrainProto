## 0. Как всё началось

Сессия началась с запроса «оцени проект, чего не хватает, слабые места». Оценка показала:
проект широкий (23 фичи на 18.08), но мелкий там, где тренажёру нужна глубина — WASD-камера вместо
дрона, нет цикла обучения, нет git/билдов, один горный регион, «сахарные» визуалы. Составлен план из
7 пунктов, выполнен «всё по порядку». Затем по запросу «максимальный реализм» — переписан визуал,
проведено мультиагентное исследование гиперреализма (7 агентов, 107 находок), выполнены 3 спринта
из его дорожной карты. Затем итеративные фиксы по реальным облётам Андрея (он находил — я чинил),
кампания производительности 25→57 FPS, HUD «адаптивный минимум», главное меню, переключатель камер.

## 1. Семь пунктов первичного плана (18.08, все выполнены)

## 2. Реализм-проход и исследование

- Первый проход (18.08): ACES (позже заменён на AgX), SSAO+SSIL, объёмная дымка, 4 каскада теней
  (позже 2), TAA+FXAA; деревья кросс-карты (3 верт + 1 гориз) с процедурной текстурой листвы
  (_foliage_tex: пучки с просветами, ярусы у ели, свет сверху/снаружи; --foliagedump); трава
  (пучки-кросс-карты, атлас 2×2); шейдер земли с шумовой вариацией; лунная ночь.
- **Исследование гиперреализма** (Workflow, 7 агентов: youtube-refs, sim-sota, godot-caps, fpv-camera,
  data-sources + критик скриншотов + синтез): 107 находок → docs/hyperrealism_research.md
  (10 пробелов TL;DR, 9 таблиц по слоям, референсы, дорожная карта 3 спринта, ловушки).
  Артефакт: https://claude.ai/code/artifact/a6206207-18dd-4998-90d6-1ae0aa9e4804
- **Спринт 1 «из игры в видео»**: воздушная перспектива (fog_density ×40 от пресета, aerial_perspective
  0.85, цвет к небу), AgX (tonemap_white 4), тени облаков (global uniforms cloud_shadow_tex/params во
  всех шейдерах поверхностей, движутся по ветру), Mie-ореол+дымка горизонта в sky-шейдере, ночь с
  редкими тёплыми окнами (45% домов спят), приглушённые стены/крыши; **FPV-тракт через SubViewport**:
  рендер в 640×480–1280×960 (по качеству), эквидистантный ремап 150°, OSD Betaflight в отдельном
  viewport'е (впечатан в сигнал: рвётся вместе с картинкой), интерлейс/хрома-блюр, ступенчатая
  деградация аналога (цвет→ч/б→tearing→roll→снег) с Poisson-бурстами, jello от газа, автоэкспозиция
  с запаздыванием, veiling glare от солнца, «характер камеры», цифровой линк (блоки/фриз/SIGNAL LOST);
  основной 3D-viewport отключается в FPV (disable_3d) — FPV быстрее обычного вида; SSAO-тюнинг,
  пресет overcast (клавиша 8), солнце по эфемеридам NOAA (--date/--time).
- **Спринт 2 «живой ландшафт»**: fetch_landcover.py — ESA WorldCover 10 м читается ОКНОМ из COG на S3
  через HTTP-Range (класс RangeFile, ~10 МБ на регион); bake_overlay.py строит маску биомов 4096²
  (0 прочее/1 лес/2 дорога/3 застройка/4 пашня/5 луг/6 кустарник/7 вода/8 голая/9 болото) + галечные
  русла; terrain.gdshader по классам: лес=подстилка вблизи+тёмный полог вдали (ОТНОСИТЕЛЬНО спутника,
  т.к. Sentinel очень тёмный ~0.02 линейно), пашня=парцеллы Вороного 220 м (посев/стерня/борозды/межи),
  луга лоскутные; mask_debug (--maskdebug); scatter.gd: виды по классу и высоте DEM (бук<1150, ель
  1150–1550, криволесье, полонины; ива в поймах, ничего на пашне), плотность по качеству; трава
  4 видов по биому с цветом от спутника (vertex textureLod) и камнями; вода мутная серо-зелёная.
- **Спринт 3 «село/дороги/жизнь/тепло»**: крыши шифер45/жесть-зел20/корич15/красн15/тёмн5 (%),
  стены AO+грязевой поясок+±8%; yards.gd — усадьбы стримингом (чанки 512 м, радиус 1.2 км, AGL<900):
  участок по ориентации дома, забор-штакетник (процедурная текстура, калитка), огород+AO-пятно
  (Decal, fade 400–500 м, max_clustered_elements=2048), плодовые деревья; дороги: ширины по классу
  OSM (track 3 м…motorway 9 м), track/service/unclassified гравий, светлые грунтовки в запечке;
  traffic.gd — 40 машин по дорогам OSM (не track/service), правая сторона, развороты, фары ночью;
  стога (тип 5 в scatter); **тепловизор**: global uniform thermal_params + ветки во всех шейдерах
  (ALBEDO=0, EMISSION=температура: вода .12, лес .27, луг .33, пашня .42+стерня, застройка .40,
  дорога .66, стены .56, окна горящие .85, крыши .68, техника .88, пехота .95, обломки 1.0 остывают;
  юг склона теплее, ночь ×0.72), thermal.gd — override-материалы для StandardMaterial-мешей
  с СОХРАНЕНИЕМ прежних override (баг с куполом РЭБ), LWIR-пост в fpv.gdshader: 256×192 билинейно,
  AGC по НИЖНЕЙ части кадра (иначе небо ломает окно), ореол, «кипение»+FPN, палитры (Y), FFC-фризы
  0.4 с каждые 45–120 с, FOV 42°, 25 к/с, без jello (глобальный затвор), автоэкспозиция off.

объекты/примитивы. Флаги атрибуции: --nograss --noforest --noyards --notraffic.

## 10. Грабли (уроки, чтобы не наступать снова)

1. height_at обязан совпадать с мешем и по узлам, И по треугольникам (билинейность ≠ меш).
2. GDScript: значения из Dictionary/Array = Variant → «Cannot infer type»; аннотируй явно.
3. material_override нельзя слепо сбрасывать в null — сохраняй прежний.
4. LWIR-камеры без rolling shutter — «желе» на тепловизоре выдаёт симуляцию.
5. AGC тепловизора считай по земле (нижние 2/3), иначе холодное небо ломает окно.
6. Sentinel-подложка тёмная (~0.02 линейно) — «абсолютные» цвета поверх неё светятся; работай
   относительно macro-цвета.
7. WorldCover «застройка» покрывает всё село — траву там глушить нельзя, только внутри зданий/грядок.
8. Overpass: 5 зеркал с ретраями обязательны; основное зеркало банит (429/refused).
9. STAC ищи по bbox всего AOI, не по центру (иначе один MGRS-тайл).
10. Retina: без stretch canvas_items UI вдвое мельче задуманного.
11. Пересборка «всего вокруг камеры» — антипаттерн; всегда чанки с кэшем.
12. GEN-очереди сортируй по расстоянию до камеры (по курсу — первым).
13. Volumetric fog глобальной плотностью = молоко; туман — локальными FogVolume.
14. Флаги CLI не должны перезаписывать пользовательские сохранённые настройки.
15. Плоским объектам (дороги/вода/трафик) тени не нужны; деревьям — только вблизи.
16. Полный список ранних граблей — README «Грабли» (winding, 16-бит PNG, анизотропия, height fog,
    звёзды, горные озёра, качание деревьев).
