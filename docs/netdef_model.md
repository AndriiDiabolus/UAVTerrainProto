# Полигон «Сетевой заслон» — модель и результаты

> Отдельная испытательная среда внутри UAV Terrain Proto: проверка физической защиты
> критических объектов (в первую очередь АЗС) сетевыми заслонами на аэростатах, коптерах
> или мачтах — против «Шахедов», «Гербер», «Ланцетов», «Молний» и FPV.
>
> Создан 20.09.2026. Этап 1 — технология и доказательство применимости.
> Этап 2 (ценообразование и экономика в сравнении с альтернативами) — отдельно, см. §7.

---

## 1. Что это и как запускать

Три режима на одном расчётном ядре — **сцена и статистика считаются одним и тем же кодом**,
поэтому картинка не расходится с цифрами.

```bash
./run.sh -- --netdef                     # 3D-полигон: объект, заслон, волны угроз
./run.sh -- --netbatch=600               # Монте-Карло по всем конфигурациям → CSV + сводка
./run.sh -- --netsweep=250               # развёртка геометрии рубежа: где ставить и на какой высоте
./run.sh -- --nettest                    # самопроверки физики (27 проверок, exit 0/1)
```

Полезные флаги: `--netscen=azs_aero_hd` (конфигурация), `--netwave=shahed` (тип угрозы),
`--netwind=3,10,17` (ветры), `--netout=<каталог>` (куда писать CSV), `--netshot` (съёмка кадров),
`--region=steppe` подставляется автоматически — ровная степь с трассой.

Клавиши в 3D: `Z` волна · `U` тип угрозы · `O` конфигурация · `K` ветер · `[` `]` рубеж ·
`L` замедление ×0.25 · `X` показать/скрыть полотно.

Файлы: `godot/scripts/netdef_model.gd` (физика), `netdef_batch.gd` (прогоны и тесты),
`netdef.gd` (сцена), `netdef_hud.gd` (панели). Данные прогона: `docs/netdef/`.

## 2. Физическая модель

### 2.1 Полотно

Погонная масса шнура `μ = ρ·π·d²/4`, удельная масса полотна с квадратной ячейкой:

```
m_уд = (2 / cell) · μ · 1.25          кг/м²     (1.25 — узлы, кромка, ремвставки)
F_разр = σ · d²                        кН        (σ: Dyneema 0.80, нейлон 0.25, трос 1.15 кН/мм²)
заполненность = 1 − (1 − d/cell)²
```

Ключевое следствие: **лёгкое полотно из Dyneema почти ничего не весит** — ячейка 0.5 м,
шнур 3 мм даёт 0.034 кг/м², то есть полотно 30 × 178 м весит 183 кг. Нейлон 5 мм с ячейкой
0.4 м — уже 0.14 кг/м², вчетверо больше, и аэростат его не поднимает.

### 2.2 Носитель

Аэростат: подъёмная сила `(ρ_возд − ρ_He)·V·e^(−h/8400)` минус оболочка (площадь сферы ×1.15,
0.20–0.22 кг/м²) минус привязной трос. 150 м³ поднимает ~100 кг, 400 м³ — ~330 кг.

**Инженерное правило:** свободная подъёмная сила должна перекрывать вес полотна примерно
вдвое, иначе привязь ложится по ветру и рубеж теряет высоту. Модель считает `запас ×N`
и помечает конфигурацию нереализованной, если носитель не тянет.

### 2.3 Ветер — главный ограничитель

Лобовое сопротивление полотна `F = ½ρv²·A·заполненность·1.2`. Нижняя кромка притянута к
грунтовым анкерам, поэтому ~60 % нагрузки уходит в анкеры, остальное — в носитель:

```
наклон привязи = atan( (F_полотна·0.4 + F_оболочки) / свободная подъёмная сила )
рабочая высота кромки = h_ном · cos(наклон)
```

На конфигурации «аэростаты 400 м³, полотно 30 × 178 м»: при 3 м/с наклон 8° (кромка 188 из 190 м),
при 10 м/с — 57° (кромка 104 м), при 17 м/с — 77° (кромка 42 м). Выше предела носителя
(18–22 м/с) заслон спускают лебёдкой.

### 2.4 Акт перехвата

Порядок разрешения (каждый шаг может закончить попытку):

1. **Заслон поднят?** Носитель не тянет полотно или ветер выше предела → изделие проходит.
2. **Высота пересечения.** Изделие держит крейсер и снижается на объект с дальности `r_сниж`
   (полого 350 м, средне 700 м, пикирование ≈ высота × 0.84). Высота на рубеже
   `h = h_крейс · min(1, r_рубежа / r_сниж)`. Выше верхней кромки — перелёт, ниже нижней — проход низом.
3. **Щель между секциями.** Щель шириной `gap` пропускает изделие только «чистой» частью
   `(gap − размах)`: крылом за кромку полотна оно всё равно цепляется.
4. **Уклонение.** Изделия с видеоканалом (FPV, «Молния») — оператор видит полотно: 22 % попыток отворот.
5. **Геометрия ячейки.** Пролёт сквозь окно возможен при `размах < ячейка` с вероятностью
   `((cell − span)/cell)²`; вращающиеся винты ловят шнур и при формальном пролёте
   (квадрокоптер 0.92, толкающий винт 0.55).
6. **Энергия.**
   ```
   E = ½·m·(v·cos γ)²                                    γ — угол траектории на рубеже
   E_ёмк = n_нитей · F_разр · ход_полотна · 0.5 + F_погл · ход_поглотителя
   n_нитей = 2·(⌈размах/ячейка⌉ + 1),  0.5 — нити нагружаются неравномерно
   ```
   `E ≤ E_ёмк` → задержан. Иначе прорыв с остаточной скоростью `√(2(E − E_ёмк)/m)`.
7. **Перегрузка.** `n_g = v_n² / (2·ход·g)`. Выше предела планера (Шахед 6 g, «Гербера» 3.5 g,
   FPV 12 g) конструкция разрушается даже при прорыве — дальше летят обломки по баллистике.
8. **Подрыв.** Инерционно-ударный взрыватель срабатывает с вероятностью, растущей от перегрузки
   (`impact`: от 8 g, `contact`: от 4 g).

### 2.5 Поражение объекта

Избыточное давление — формула Садовского, ТНТ-эквивалент БЧ ×1.1:

```
ΔP = 95·W^⅓/R + 390·W^⅔/R² + 1300·W/R³        кПа
```

Сверка с таблицами: 50 кг на 20 м → 39 кПа, на 50 м → 9.6 кПа, на 100 м → 4.1 кПа.

Осколки: `p = 1 − exp(−плотность·площадь·0.25·e^(−R/120))`, 900 убойных осколков на кг ВВ.

Объект — набор элементов с координатами, миделем и критическим давлением. Для АЗС:
подземные резервуары (70 кПа, критично), ПРК (20 кПа, критично), навес (7 кПа), операторная
(12 кПа), модуль СВГ (35 кПа, критично, вторичный взрыв), бензовоз под сливом (25 кПа).
Поражение любого критического элемента = объект выбыл из строя.

## 4. Что показали прогоны

Базовый уровень: **без заслона любое долетевшее изделие выводит АЗС из строя в 100 % попыток**
(площадка компактная, критические элементы в радиусе 25 м).

### 4.1 Заслон физически работает против основной массы угроз

Конфигурация «аэростаты 400 м³, рубеж 300 м, полотно 12…190 м, тормозной поглотитель», ветер 3 м/с:

| угроза | задержано | объект выбыл: было → стало |
|---|---|---|
| Шахед-136 | 86 % | 100 % → 14 % |
| Гербера | 64 % | 100 % → 37 % |
| «Молния» | 70 % | 100 % → 30 % |
| FPV 7" | 68 % | 100 % → 32 % |
| Ланцет-3 | 22 % | 100 % → 78 % |
| Шахед-238 | 63 % | 100 % → 57 % |

### 4.2 Решающий элемент — не сеть, а якорный энергопоглотитель

Шахед-136 на 50 м/с несёт 250 кДж. Полотно из 3-мм Dyneema отдаёт около 170 кДж —
этого не хватает, изделие рвёт сеть. Тормозное устройство на анкерах (35 кН × 15 м = 525 кДж)
закрывает разрыв с запасом. В самопроверках это зафиксировано отдельным тестом:
без поглотителя — прорыв, с поглотителем — задержание при 7 g.

**Вывод для конструкции:** полотно должно только зацепить изделие; энергию гасит анкерный узел.
Это резко удешевляет сеть и облегчает носитель.

### 4.3 Рубеж надо ставить ближе, а не дальше

Изделие снижается на объект, поэтому чем ближе рубеж, тем ниже точка пересечения полотна.
Развёртка по смеси налёта (Шахед 40 %, Гербера 25 %, «Молния» 15 %, FPV 10 %, Ланцет 10 %):

| кромка \ рубеж | 80 м | 140 м | 200 м | 320 м | 500 м |
|---|---|---|---|---|---|
| 60 м | 34 % | 53 % | 64 % | 86 % | 85 % |
| 100 м | 20 % | 30 % | 37 % | 64 % | 62 % |
| 180 м | 24 % | 15 % | 23 % | 30 % | 36 % |
| 260 м | 24 % | 20 % | 18 % | 20 % | 20 % |

*(в клетке — остаточный риск вывода объекта из строя; без заслона 100 %)*

Лучшие геометрии по худшему из проверенных ветров: рубеж 80–140 м с кромкой 180–220 м,
остаточный риск 24 %, носителей всего **16–35** вместо 63 у дальнего рубежа. Ближний рубеж
одновременно дешевле и эффективнее — но требует проверки по ударной волне, что модель и делает.

### 4.4 Ветер — главный ограничитель, а не энергия удара

Та же конфигурация при усилении ветра: 3 м/с — риск 14 %, 10 м/с — 63 %, 17 м/с — 92 %.
Причина не в прочности, а в геометрии: кромка проседает со 190 до 42 м, и изделия проходят верхом.

**Следствие:** заслон нужно считать не одной цифрой, а профилем доступности по розе ветров района.
Для степи юга Украины это значимая доля дней в году, и это нужно закладывать в ТЗ.

### 4.5 Против пикирующих изделий вертикальный заслон не работает

Ланцет заходит с 300–600 м и пикирует под ~50°: 72 % попыток проходят над верхней кромкой.
Вертикальная штора закрывает коридор крейсерских высот, но не защищает сверху.
Горизонтальная «крыша» над объектом — отдельная задача (и отдельная масса полотна).

### 4.6 Мелочи, которые видно только в расчёте

- Ячейка 0.5 м против FPV 7" (размах по винтам 0.36 м): пролёт сквозь окно — менее 2 % попыток,
  винты наматывают шнур. Уменьшать ячейку ради FPV не нужно — это утроит массу полотна.
- Изделие, задержанное сетью, часто **подрывается на полотне**: на рубеже 200–300 м это
  безопасно для объекта (ΔP около 2 кПа), на рубеже 80 м — уже нет. Оптимум рубежа
  ограничен снизу именно ударной волной, а не геометрией перехвата.
- Разрывы между секциями дают 4–14 % утечек: щель 4 м пропускает FPV заметно чаще,
  чем Шахед с размахом 2.5 м.

## 5. Ограничения модели

Честный список того, чего модель **не** учитывает:

1. Динамика полотна как ткани (волны, отскок, последовательное рвание ячеек) — заменена
   энергетическим балансом. Для оценки достаточно, для конструирования узла нужен расчёт МКЭ.
2. Обледенение и намокание полотна (рост массы и парусности) — не смоделировано, зимой
   допустимый ветер будет ниже.
3. Повторяемость: после задержания секция выведена из строя, время замены полотна не учитывается.
4. Заслон как помеха собственной инфраструктуре (проезд к АЗС, ЛЭП, авиация, разрешения) —
   вне модели, но это реальный фактор внедрения.
5. Радиолокационная и оптическая заметность самого заслона, риск его подавления.
6. Вероятность отказа взрывателя, поведение БЧ при ударе о сеть — оценочные коэффициенты.
7. Поведение оператора FPV (22 % уклонения) — экспертная оценка, не измерение.

## 6. Что проверять дальше (техническая часть)

- Горизонтальная «крыша» над объектом против пикирующих (Ланцет) — добавить как тип секции.
- Многорубежная схема: дешёвый ближний + высокий дальний, и что это даёт по смеси налёта.
- Время развёртывания коптерного заслона против времени подлёта (радиус обнаружения → подъём).
- Режим «сектор угрозы»: закрывать 120–180° вместо кольца, экономия носителей в 2–3 раза.
- Проверка энергетики узла поглотителя: реальные разрывные ленты и фрикционные тормоза.

## 7. Этап 2 — экономика (вынесен отдельно)

В модели уже заложены поля стоимости: носители (9–42 тыс. $), поглотители (120–900 $),
стоимость изделий угроз (500–120 000 $) и стоимость объектов (АЗС 1.2 млн $, подстанция 9 млн $,
нефтебаза 6 млн $). Этого достаточно, чтобы на этапе 2 посчитать:

- себестоимость комплекта на объект (носители + полотно + анкеры + лебёдки + гелий + расчёт);
- стоимость эксплуатации (гелий, замена полотна, смены дежурства, ресурс оболочки);
- размен стоимости: сколько стоит сбить «Шахед» заслоном против ЗРК/мобильных групп/РЭБ;
- ожидаемый предотвращённый ущерб = снижение риска × стоимость объекта × частота налётов;
- срок окупаемости по объектам разного класса.

Расчёт не делается до тех пор, пока не зафиксированы технические параметры комплекта —
иначе экономика считается по выдуманной конструкции.
