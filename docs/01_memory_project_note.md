**UAV Terrain Proto** (создан 2026-08-13): `/Users/andriidiablo/Desktop/UAVTerrainProto` — работающий Godot 4.6 прототип: полёт над реальными Карпатами 52×52 км (Говерла), ~44 FPS на M4 Pro.

Контекст: шаг 1 плана из мультиагентного исследования «Google Flight Simulator / VR-обучающие среды» — строить на открытых данных (AWS Terrain Tiles + Sentinel-2 cloudless EOX), без Google (лицензии закрывают оборонку, покрытия Украины у Google нет). Шаг 2 плана — разговор с каналом (школа дронов / Brave1) — ещё не сделан.

Данные тянет `tools/fetch_terrain.py` (Python+Pillow, без GDAL). Рельеф — AWS Terrain Tiles (открытая лицензия).

Подложка: 13.08.2026 заменена с EOX (CC-BY-NC) на **Sentinel-2 L2A COG** из открытого бакета sentinel-cogs (AWS Open Data) — коммерческая лицензия Copernicus, для гранта [[project-brave1-sim]] чисто. Логика в новом `tools/s2_albedo.py`: STAC-поиск безоблачных сцен → готовый TCI-COG → репроекция UTM→WebMercator под extent DEM → домозаичивание неск. сцен (AOI на границе UTM-зон 34/35). Требует venv `tools/.venv` (numpy, pyproj, tifffile, imagecodecs). Проверено в движке: 54 FPS, подложка ложится на рельеф. NC-данные из репо/кеша вычищены.

Слой погружения (13.08): OSM через Overpass (кеш tools/osm_cache) — дороги/реки запечены в текстуру, дома по footprint'ам, ели стримятся чанками по маске леса. Старт над Ворохтой. Боевой слой: танки/БТР/пехота патрулируют реальные дороги OSM, поражение ЛКМ/тараном, маркеры-столбы, счёт (targets.gd). Погода: 5 пресетов день/ветер/шторм/закат/ночь + дождь/молнии (weather.gd, клавиши 1-5/P). Физика дрона с инерцией/кренами (flycam.gd). Звук процедурный без файлов — моторы/ветер синтез + позиционные взрывы (sound.gd).

Симуляционный слой (18.08, по аудиту): 4 приоритета «от демо к тренажёру» — (1) **коллизии+краш**: сетка препятствий 64м (здания/столбы/деревья), удар→падение дрона, R-рестарт; (2) **LOS-сигнал**: RSSI падает за рельефом (трассировка луча оператор→дрон), не просто по дальности; (3) **фиксированный сид** (--seed=N) для повторяемых сценариев; (4) **лётная модель**: гравитация+тяга с авто-зависом, вертикаль≠горизонталь, турбулентность ветра. Аудит показал: до этого мир был «декорацией» (нельзя столкнуться/потерять сигнал/повторить). Осталось для тренажёра: ИИ целей (реагируют/стреляют), баллистика выстрела, тени объектов/SSAO, плотность леса.

Реализм-апгрейд (17.08): (1) detail texturing земли — реальные CC0-фототекстуры Poly Haven (aerial_grass_rock/aerial_mud_1/aerial_rocks_04 + normal): трава на пологих, камень на склонах, грунт на бурых пятнах, фото принимает цвет спутника; ключ — анизотропная фильтрация (level=16), иначе под скользящим углом мыло. (2) дома — текстур. стены (beige_wall_001) + двускатные крыши PrismMesh (grey_roof_01), per-instance цвет. Все текстуры **CC0** (tools/fetch_textures.py) — чисто для оборонки, в отличие от Google. Запуск с рабочего стола: «Полёт Карпаты.app».

Ключевой урок дебага (полдня): невидимый меш при правильном AABB = перевёрнутый winding треугольников + бурая ground-полусфера ProceduralSky, маскирующаяся под «рельеф без текстуры». Полный список граблей в README проекта.
