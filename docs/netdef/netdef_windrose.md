# Доступність сітьового заслону за реальними вітрами

Вітер: ERA5 hourly via Open-Meteo archive API (CC BY 4.0), wind_speed_100m, 2023–2025, почасово, висота 100 м (середина полотна). Метрика — очікуваний ризик вивести АЗС з ладу на одну атаку суміші нальоту. «Шахед поверх» — частка годин, коли кромка нижча за висоту перетину рубежу типовим Шахедом або заслін спущено.

ERA5 — годинні середні по комірці ~30 км: пориви й локальні ефекти (пагорби, забудова) не враховані, реальний вітер на майданчику треба міряти.
