# Что не хватает для гиперреализма — UAV Terrain Proto

Сводный отчёт теххудожника по результатам исследования 6 направлений (YouTube-референсы реальных полётов, SOTA симуляторов и игр, возможности Godot 4.6, FPV-камера/видеолинк, открытые датасеты, критика текущих скриншотов).

Дата: 18.08.2026. Проект: Godot 4.6 Forward+, macOS M4 Pro (44–46 FPS на «высоком»), 52×52 км Карпат (SRTM 30 м → меш 1024², Sentinel-2 10 м/px), OSM-застройка/дороги/вода, кросс-карты деревьев/травы, свой sky-шейдер, FPV-постэффект.

Ограничения, под которые сведён отчёт: только открытые/CC0 данные и ассеты (без Google, без NC/ND-лицензий), Godot 4.6 без плагинов (MIT-плагины — как опция), целевые ПК школ слабые (нужны уровни качества).

Скриншоты-основа: `valley2.png` (240 м AGL над долиной), `ground2.png` (2.5 м AGL), `night4.png` (ночь, 34 м AGL).

## 2. Что уже хорошо (не трогать)

- **География и композиция**: форма долины, петляющая река, село вдоль реки/дорог, гребни на горизонте узнаваемо карпатские; масштаб домов относительно деревьев и дорог правдоподобен. Пайплайн DEM/OSM/Sentinel-2 переделывать не нужно — менять только шейдинг и расстановку.
- **Базовое освещение**: DirectionalLight + 4 каскада до 6 км работают; крупные тени рельефа (левый склон под лесом на valley2) присутствуют; дневная экспозиция в разумном диапазоне. Нужна тонкая настройка (тонмап, ambient, туман, cloud shadow), а не смена системы света.
- **Уже правильные приёмы**: белёсая полоса неба у горизонта (ground2), дым из труб, часть крыш красных/тёмных, ветроуказатель, чистый минималистичный HUD, звёзды и рваные силуэты облаков ночью как концепция — усилить, не заменять.
- **Технический фундамент**: Forward+, TAA, SSAO/SSIL, volumetric fog, погода/молнии/дождь, FPV-постэффект (рыбий глаз, виньетка, хроматика, зерно, OSD) — всё это база, которую надо перенастроить, а не переписать.

## 5. Дорожная карта: 3 спринта

### Спринт 1 (1–1.5 недели): «Из игры в видео» — свет, цвет, FPV-тракт, ночь
Только шейдинг/настройки, ноль новых данных, почти ноль perf-стоимости; максимальный визуальный сдвиг за минимум времени.

1. Воздушная перспектива: `fog_*` + `fog_aerial_perspective` + lerp в шейдере террейна; горизонт неба белеет; Mie-ореол в sky-шейдере (1 д).
2. Тонмап/палитра: AgX + `adjustment` (sat 0.8) + LUT 16³ к оливе; albedo травы/крон/стен снизить; проверить sRGB текстур (0.5 д).
3. Тени облаков через global shader parameter во всех шейдерах поверхностей + движение по ветру (1 д).
4. Ночь: 15–25 % тёплых окон по хэшу, ambient 0.02–0.05, облака ×0.05–0.12, луна как DirectionalLight, фонари = столб + SpotLight + halo, зарево над сёлами в sky-шейдере (1.5 д).
5. FPV-тракт: SubViewport 720×480 4:3 с OSD внутри → TextureRect с fpv.gdshader; интерлейс/chroma blur/25–30 Гц; ступенчатая деградация аналога по `link_q` + бурсты; jello от газа; экспозиметр с запаздыванием + veiling glare от солнца; «характер» камеры (шарпинг, приподнятый чёрный) (3.5 д).
6. Мягкие тени: `light_angular_distance` 0.5, blend splits, normal bias; SSAO радиус/интенсивность (0.5 д).
7. Пресет overcast + эфемериды солнца (1 д).

Ожидаемый результат на скриншотах: valley2 — гребни ступенчато голубеют, луга оливково-приглушённые, пятна облачных теней по склонам, стены домов не горят; night4 — тёмное село с редкими тёплыми окнами, приглушённые облака, конусы фонарей, шумная картинка камеры; FPV — 4:3 картинка с интерлейсом и OSD, которая рвётся и седеет при потере сигнала.

### Спринт 2 (2 недели): «Живой ландшафт» — данные, растительность, земля вблизи, вода
1. Данные: `fetch_landcover.py` (WorldCover) + `fetch_canopy.py` (ETH 10 м) + OSM leaf_type/landuse/tree_row → маска биомов RGBA 4096²; расширить `fetch_osm.py` (surface/width/bridge/railway, building types, roof:shape) и `fetch_lakes.py` (relations, riverbank, shingle) (4 д).
2. Лес: плотность/виды/высота из масок, тёмное альбедо + AO-градиент + per-instance tint, затемнение террейна под маской, резкая опушка, «полог»-слой с 800 м, LOD0 меши Poly Haven (fir/pine/tree_small) + alpha_to_coverage; ветер через Shader Globals (5 д).
3. Трава/земля вблизи: 4–6 пучков без обводки, тинт от спутника, шумовой fade 50–90 м, ветер; detail-текстуры земли с height-blend + dual scaling + tile-scramble + макро-normal из DEM; клаттер камней (4 д).
4. Вода: серо-зелёная мутная + Fresnel к небу + ветровая рябь; галечное русло ×2–3 ширины + пена на уклонах; ивняк вдоль берегов (2.5 д).
5. Парцеллы лугов/полей: OSM farmland/meadow → hue-вариация, межи, борозды по оси поля, лесополосы плотные (3 д).

Ожидаемый результат: valley2 — тёмное «сукно» ельника с жёсткой опушкой на фоне лоскутных оливковых лугов, серо-белое галечное русло с тёмной водой; ground2 — разнотравье без обводки, цвет совпадает с землёй, видна фактура почвы и камни, деревья вблизи объёмные с тенями, горизонт луга ломается кустами.

### Спринт 3 (2 недели): «Село, дороги, жизнь, тепловизор, школьные ПК»
1. Застройка: двускатные крыши по длинной оси + палитра, трубы, albedo стен + AO к основанию + Decal-AO вблизи, типы зданий по OSM/GHSL, visibility_range + fade по тайлам (4 д).
2. Усадьбы: Voronoi-участки → заборы MultiMesh, огород-маска, 2–8 плодовых деревьев, сарай (4 д).
3. Дороги: ширина/материал по OSM, светлые грунтовки с колеёй и зелёной полосой, обочина, SDF-маска в террейн (убрать двойное изображение), Decal-лужи вблизи, `wetness` из погоды (2.5 д).
4. «Жизнь»: машины по OSM way (фары ночью), стога, столбы, тропы дом→дорога, биллборды людей/скота (3 д).
5. Тепловизор: `thermal_mode` во всех материалах + постшейдер 256×192 (шум, AGC, halo, палитры, FFC-фризы) + узкий FOV; цифровой линк (блоки/фриз/Signal Lost) (5 д — можно вынести в спринт 3b).
6. QualityManager: Low/Mid/High/Ultra по таблице 3.9, автодетект GPU, замер на M4 Pro и на Intel UHD-классе; FSR2/FSR1/Bilinear; cast_shadow только LOD0 (3 д).

Ожидаемый результат: valley2 — село читается как участки с заборами и огородами, крыши шифер/жесть/красные, светлые грунтовки с обочинами, машины на дорогах, стога на лугах; night4 — тепловизионный white-hot режим с горячими крышами/техникой и FFC-фризами; Low-пресет держит 30+ FPS на слабом ПК за счёт 640×480 FPV-рендера и импосторов.

Опционально после спринтов (High/Ultra): SDFGI, volumetric fog в долинах + FogVolume, объёмные облака clayjohn v2, SSR, motion blur Compositor, микрорельеф vertex-displacement, задержка видеотракта, сезонные подложки Sentinel-2, VIIRS-огни, ветер по GWA/GFS.

## 6. Чего НЕ делать (ловушки)

- **Не переезжать на Unity/UE5**: все пробелы закрываются в Godot 4.6 штатно; UE5 Lumen/Nanite (Uncrashed) требует RTX 2060+ — противоречит требованию школьных ПК. Godot 4.6 сам даёт +20–33 % в лесных сценах.
- **Не покупать SpeedTree/Quixel/Megascans/ассет-паки**: SpeedTree платный и ветер не переносится; Quixel/Fab — не CC0; Sketchfab — проверять каждую модель; OGA — смешанные лицензии. Всё нужное есть на Poly Haven, ambientCG, Quaternius, Kenney (CC0).
- **Не использовать NC/ND-данные**: FABDEM (CC BY-NC-SA), NASA Harvest Ukraine field boundaries (CC BY-NC-ND), EOX Sentinel-2 cloudless (CC BY-NC-SA), Dynamic World (только через Google Earth Engine), Google-тайлы любого рода. Open-Meteo API бесплатен только некоммерчески — для продукта брать GFS/ECMWF Open Data или заранее скачанные пакеты.
- **Не менять DEM ради визуала**: лучше 30 м открытого для Украины нет (GLO-30 — тот же порядок; LiDAR открытого нет); микрорельеф — процедурный шум/normal, а не новые данные. GLO-30 стоит брать ради точности высот (LOS/terrain-following), а не картинки, и только после уплотнения меша.
- **Не делать фотограмметрию/3D-тайлы**: нет открытых источников для 52×52 км, а лицензии Google Photorealistic 3D Tiles запрещены по условиям проекта.
- **Не рендерить FPV в полном разрешении с наложенными «CRT»-полосками**: реальная картинка — 640×480 с интерлейсом; низкоразрешённый SubViewport одновременно реалистичнее и быстрее.
- **Не копировать шрифт Betaflight OSD** (GPL) — рисовать свой пиксельный 12×18 или брать CC0/OFL.
- **Не делать дороги декалями** (лимит 512 кластерных элементов на кадр в Forward+, стоимость по площади экрана) — дороги остаются лентами + SDF-маска в террейне; Decal только для луж/грязи вблизи.
- **Не ставить SDFGI/VoxelGI/volumetric на Low/Mid**: недоступны на Mobile/Compatibility и дороги; на слабых ПК «фотография» достигается небом, тенями облаков, detail-текстурами, импосторами и низким разрешением FPV.
- **Не брать HTerrain (Zylann)**: не в активной разработке, GDScript, медленнее; если нужен плагин террейна — только Terrain3D (MIT) или свой меш с заимствованными приёмами шейдера.
- **Не тратить время на occlusion culling** на открытом рельефе — почти не работает; резерв FPS — visibility ranges, LOD, импосторы, разрешение.
- **Не переделывать пайплайн DEM/OSM/Sentinel-2** — макро-география уже узнаваемо карпатская; менять только шейдинг, расстановку и данные-маски поверх.
- **Не рассчитывать на LPVGI** — в стабильном Godot 4.6 его нет (только proposal/кастомные сборки).
